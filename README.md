# 🌍  Remote Sensing & GeoAI Consultant- Google Earth Engine - Dr. Haifa AL Mohammad

Welcome to my GitHub profile!  I am a consultant specializing in leveraging **Google Earth Engine (GEE)**, **Remote Sensing, GIS**, and **Machine Learning** for environmental monitoring, land resource management, and precision agriculture.

---

### 🔬 Core Expertise & GEE Applications

- **🌱 Soil Organic Carbon (SOC) Mapping**: Predictive spatial modeling and SOC assessment using Sentinel-2/Landsat timeseries and field calibration in GEE.
- **🗺️ Land Use & Land Cover (LULC)**: Automated change detection, Machine Learning classification (Random Forest/SVM), and Land Degradation Neutrality (LDN) monitoring.
- **📊 Spectral Indices Toolkit**: Multi-spectral processing workflows for computing NDVI, EVI, SAVI, NDWI, BSI, and moisture/vegetation dynamics.
- **⚡ Tech Stack**: Google Earth Engine (JavaScript API & Python `ee`), Python (`geemap`, `geopandas`, `rasterio`, `scikit-learn`), QGIS, ArcGIS Pro.
